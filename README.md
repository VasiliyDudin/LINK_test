## 📖 Описание

**JustPass** — это клиент-серверное веб-приложение для генерации и временного хранения паролей. Все сгенерированные пароли хранятся **только в рамках сессии браузера**. Приложение разработано в минималистичном интуитивно понятном интерфейсе в стилистике компании **ЛУКОЙЛ**.

## 🚀 Запуск приложения

### 1. Запуск сервера

Сервер запускается по адресу:  
**`https://localhost:7227`**

> Если требуется изменить хост или порт, отредактируйте файл:  
> `JustPass.Server/Properties/launchSettings.json`

```bash
cd JustPass.Server
dotnet run
```

### 2. Запуск клиента

Клиент также использует **`https://localhost:7227`** для взаимодействия с сервером.  
Настройки прокси уже прописаны в файлах:
- `App.jsx`
- `PasswordGenerator.jsx`
- `vite.config.js`

```bash
cd JustPass.Client
npm install
npm run dev
```

После запуска клиента приложение будет доступно в браузере.

## 🔄 API Эндпоинты (REST)

Контроллер `PassController.cs` предоставляет следующие методы:

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| **POST** | `/api/Pass/Generate` | Генерация пароля |
| **GET** | `/api/Pass/GetHistory` | Получение истории |
| **DELETE** | `/api/Pass/ClearHistory` | Очистка истории |
| **POST** | `/api/Pass/Safety` | Оценка надежности пароля |

## 🧪 Демонстрационное шифрование

Для демонстрационных целей при передаче паролей используется **Base64**.  
Это позволяет скрыть реальные пароли от видимости при передаче в запросах.

> 📌 **Как посмотреть реальные пароли:**  
> Откройте **DevTools → Console** в браузере.

## 📦 Модели данных

### `PassRequest`
Запрос на генерацию пароля.
```json
{
  "LengthPwd": 8
}
```

### `PassResponse`
Ответ сервера с паролем.
```json
{
  "ID": "uuid",
  "Pwd": "RXEksi3J",
  "SafetyPwd": 8,
  "DateGenerated": "2026-08-01T20:44:50Z"
}
```

### `PassHistory`
История сгенерированных паролей.
```json
{
  "items": [
    { "ID": 1, "Pwd": "RXEksi3J", "SafetyPwd": 8, dateGenerated: "2026-08-01T18:50:17.2190931Z" },
    { "ID": 2, "Pwd": "B@bBM90", "SafetyPwd": 6, dateGenerated: "2026-08-01T18:51:14.2190931Z" }
  ]
}
```
