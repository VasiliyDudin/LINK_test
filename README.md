CreatReports - Генератор протоколов обучения
Назначение программы
Программа автоматически создаёт протоколы обучения в формате Microsoft Word.
На основе шаблона, данных участников и настроек формируется готовый документ.

Что нужно подготовить перед запуском
Перед запуском у вас должны быть три файла:

1. Шаблон документа - SourceTemplate.docx

  Это файл Word с разметкой документа. Вместо реальных данных в нём стоят специальные метки, например:

  {LastNameTbl} - фамилия участника

  {DocumentTitle} - заголовок документа

  Важно: файл должен называться строго SourceTemplate.docx и находиться в папке с программой.

2. Файл настроек - config.json

  Содержит информацию о сотруднике и путь к данным:

  text
  {
    "employee": {
      "lastName": "Иванов",
      "firstName": "Иван",
      "middleName": "Иванович",
      "position": "Инженер"
    },
    "documentTitle": "Протокол обучения пользователей №1",
    "csvFilePath": "/Info.csv"
  }
  Поле	Что означает
  employee.lastName	Фамилия сотрудника
  employee.firstName	Имя сотрудника
  employee.middleName	Отчество сотрудника
  employee.position	Должность сотрудника
  documentTitle	Заголовок документа
  csvFilePath	Путь к файлу с данными участников
3. Файл с данными - Info.csv

  Содержит список участников в формате CSV:
  
  text
  Фамилия,Имя,Оценка
  Петров,Петр,5
  Сидоров,Сидор,4
  Иванов,Иван,3
  Обязательные колонки: Фамилия, Имя, Оценка.

Как запустить и работать
Шаг 1. Запустите программу из консоли или Visual Studio.

Шаг 2. Программа попросит ввести путь к config.json:

text
Введите путь к config.json: C:\Projects\CreatReports\config.json
Если файл лежит в папке с программой, можно просто написать config.json

Шаг 3. Программа попросит указать, куда сохранить готовый документ:

text
Введите путь для сохранения документа: C:\Reports\Протокол_2026.docx
Шаг 4. Программа создаст документ и покажет сообщение:

text
Документ успешно создан: C:\Reports\Протокол_2026.docx
Шаг 5. Программа спросит, хотите ли вы создать ещё один документ:

text
Продолжить? (Y/N):
Нажмите Y - создать ещё один документ.
Нажмите любую другую клавишу - завершить работу.

Возможные ошибки и решения
Ошибка	Решение
"Файл не найден"	Проверьте, что все файлы лежат в указанных местах
"Некорректный формат CSV"	Проверьте колонки: Фамилия,Имя,Оценка
"Неправильный JSON"	Проверьте кавычки и запятые в config.json
"Нет доступа для записи"	Закройте файл, если он открыт в Word

Структура шаблона и откуда берутся данные
Метка в шаблоне	Откуда берётся
{DocumentTitle}	Из config.json → documentTitle
{RowNumberTbl}	Номер строки (автоматически)
{LastNameTbl}	Из Info.csv → Фамилия
{FirstNameTbl}	Из Info.csv → Имя
{EvaluationTbl}	Из Info.csv → Оценка
{Position}	Из config.json → employee.position
{LastName}	Из config.json → employee.lastName
{FirstName}	Из config.json → employee.firstName
{MiddleName}	Из config.json → employee.middleName
Рекомендации по размещению файлов
Лучше всего положить все файлы в одну папку:

text
CreatReports/
├── CreatReports.slnx
├── SourceTemplate.docx
├── config.json
├── Info.csv
└── bin/
Чек-лист перед запуском
□ SourceTemplate.docx есть в папке с программой
□ config.json есть в папке с программой
□ Info.csv есть в папке, указанной в config.json
□ Все файлы имеют правильный формат

Формат файлов
config.json - настройки программы

Поле	Тип	Описание
employee.lastName	string	Фамилия сотрудника
employee.firstName	string	Имя сотрудника
employee.middleName	string	Отчество сотрудника
employee.position	string	Должность сотрудника
documentTitle	string	Заголовок документа
csvFilePath	string	Путь к CSV-файлу
Info.csv - данные участников

Колонка	Тип	Описание
Фамилия	string	Фамилия участника
Имя	string	Имя участника
Оценка	integer	Оценка от 1 до 5
Файл должен быть в кодировке UTF-8.
