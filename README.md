CreatReports - Генератор протоколов обучения
🎯 Назначение программы
Программа предназначена для автоматического создания протоколов обучения в формате Microsoft Word. Вы просто загружаете данные участников из CSV-файла, указываете настройки в конфигурации, и программа формирует готовый документ по вашему шаблону.

📁 Что нужно подготовить перед запуском
Перед первым запуском убедитесь, что у вас есть три обязательных файла:

1. Шаблон документа (SourceTemplate.docx)
Это ваш шаблон в формате Word, в котором уже размечена структура документа. Вместо реальных данных в нём стоят специальные метки-заполнители (плейсхолдеры), например: {LastNameTbl}, {DocumentTitle}.

Важно: Название файла должно быть строго SourceTemplate.docx. Положите его в корневую папку проекта.

2. Файл конфигурации (config.json)
Здесь хранятся настройки: информация о сотруднике, проводившем обучение, и путь к файлу с данными.

json
{
  "employee": {
    "lastName": "Иванов",
    "firstName": "Иван", 
    "middleName": "Иванович",
    "position": "Инженер"
  },
  "documentTitle": "Протокол обучения пользователей №1",
  "csvFilePath": "/Info.csv"
}
3. Файл с данными участников (Info.csv)
Таблица с информацией о прошедших обучение. Должна быть в формате CSV с тремя колонками:

csv
Фамилия,Имя,Оценка
Петров,Петр,5
Сидоров,Сидор,4
Иванов,Иван,3
🚀 Как запустить и работать
Шаг 1. Запустите программу
Откройте консоль или Visual Studio и запустите приложение.

Шаг 2. Укажите путь к конфигурации
Программа попросит вас ввести полный путь к файлу config.json. Пример:

text
Введите путь к config.json: C:\Мои документы\Projects\CreatReports\config.json
Подсказка: Если файлы лежат в одной папке с программой, можно указать только имя файла: config.json

Шаг 3. Укажите путь для сохранения результата
После успешной загрузки конфигурации программа спросит, куда сохранить готовый документ:

text
Введите путь для сохранения документа: C:\Reports\Протокол_2026.docx
Если папки не существует, программа создаст её автоматически.

Шаг 4. Дождитесь завершения
Программа сообщит об успешном создании документа:

text
✅ Документ успешно создан: C:\Reports\Протокол_2026.docx
Шаг 5. Продолжить или завершить
После создания документа программа спросит, хотите ли вы создать ещё один документ:

text
Продолжить? (Y/N):
Нажмите Y — программа предложит ввести новый путь для сохранения

Нажмите любую другую клавишу — программа завершит работу

💡 Что происходит внутри
Программа автоматически:

Читает ваш файл config.json и извлекает настройки

Загружает данные участников из Info.csv

Открывает шаблон SourceTemplate.docx

Подставляет все данные в нужные места (заменяет плейсхолдеры)

Сохраняет готовый документ по указанному вами пути

⚠️ Важные моменты
Ситуация	Что делать
Программа пишет "Файл не найден"	Проверьте, что все файлы лежат в указанных местах и названия совпадают
Ошибка в CSV-файле	Убедитесь, что файл имеет три колонки: Фамилия, Имя, Оценка
Неправильный JSON	Проверьте, что в config.json все кавычки и запятые расставлены верно
Путь сохранения не существует	Программа создаст папку автоматически
Шаблон не открывается	Убедитесь, что файл SourceTemplate.docx не повреждён
🛠 Типичные ошибки и их решение
❌ "Не удалось найти config.json"
Решение: Укажите полный путь к файлу или переместите config.json в папку с программой.

❌ "Некорректный формат CSV"
Решение: Откройте Info.csv в Excel и проверьте, что первая строка содержит заголовки: Фамилия,Имя,Оценка

❌ "Плейсхолдер {EvaluationTbl} не найден в шаблоне"
Решение: Проверьте шаблон SourceTemplate.docx — все метки должны быть написаны точно как в документации.

❌ "Нет доступа для записи файла"
Решение: Закройте документ, если он открыт в Word, или укажите другой путь для сохранения.

📁 Структура файлов конфигурации
config.json
Файл конфигурации в формате JSON содержит данные об обучении и информацию о сотруднике, проводившем обучение.

json
{
  "employee": {
    "lastName": "Иванов",
    "firstName": "Иван",
    "middleName": "Иванович",
    "position": "Инженер"
  },
  "documentTitle": "Протокол обучения пользователей №1",
  "csvFilePath": "/Info.csv"
}
Поля конфигурации:
Поле	Тип	Описание
employee.lastName	string	Фамилия сотрудника, проводившего обучение
employee.firstName	string	Имя сотрудника
employee.middleName	string	Отчество сотрудника
employee.position	string	Должность сотрудника
documentTitle	string	Заголовок документа (будет подставлен в шаблон)
csvFilePath	string	Путь к CSV-файлу с данными участников (относительно корня проекта)
Info.csv
Файл с данными участников в формате CSV. Структура:

csv
Фамилия,Имя,Оценка
Петров,Петр,5
Сидоров,Сидор,4
Иванов,Иван,3
Структура CSV:
Столбец	Тип	Описание
Фамилия	string	Фамилия участника обучения
Имя	string	Имя участника
Оценка	integer	Оценка (от 1 до 5)
Важно: Файл должен быть сохранён в кодировке UTF-8 для корректного отображения кириллицы.

SourceTemplate.docx
Шаблон документа Word с плейсхолдерами, которые заменяются на реальные данные:

Плейсхолдер	Описание	Источник данных
{DocumentTitle}	Заголовок документа	config.json → documentTitle
{RowNumberTbl}	Номер строки в таблице (автоматическая нумерация)	Генерируется программой
{LastNameTbl}	Фамилия участника	Info.csv → Фамилия
{FirstNameTbl}	Имя участника	Info.csv → Имя
{EvaluationTbl}	Оценка участника	Info.csv → Оценка
{Position}	Должность сотрудника	config.json → employee.position
{LastName}	Фамилия сотрудника	config.json → employee.lastName
{FirstName}	Имя сотрудника	config.json → employee.firstName
{MiddleName}	Отчество сотрудника	config.json → employee.middleName

⚠️ Обработка ошибок
Программа обладает широким набором проверок и обрабатывает следующие ситуации:

❌ Файл config.json не найден

❌ Некорректный JSON-формат в конфигурационном файле

❌ Отсутствие файла Info.csv по указанному пути

❌ Повреждённый или некорректный CSV-файл

❌ Отсутствие шаблона SourceTemplate.docx

❌ Ошибка записи при создании документа Word

Все ошибки выводятся в консоль с понятными сообщениями. В случае возникновения критической ошибки рекомендуется обратиться к ответственному сотруднику или проверить структуру входных файлов.
