## 🎯 Назначение

Программа автоматически создаёт **протоколы обучения** в формате Microsoft Word. 

На основе:
- 📄 Шаблона документа (`SourceTemplate.docx`)
- ⚙️ Настроек в JSON-файле (`config.json`)
- 📊 Данных участников из CSV-файла (`Info.csv`)

формируется готовый документ, готовый к печати и подписи.

---

## 📁 Подготовка перед запуском

Перед первым запуском убедитесь, что у вас есть **три обязательных файла**:

### 1. 📄 SourceTemplate.docx

Шаблон документа Word, в котором вместо реальных данных стоят **метки-заполнители** (плейсхолдеры).

**Примеры меток:**
- `{LastNameTbl}` - фамилия участника
- `{DocumentTitle}` - заголовок документа
- `{Position}` - должность сотрудника

> ⚠️ **Важно:** Файл должен называться строго `SourceTemplate.docx` и находиться в папке с программой.

---

### 2. ⚙️ config.json

Файл настроек с информацией о сотруднике и путях к данным:

```json
{
  "employee": {
    "lastName": "Иванов",
    "firstName": "Иван",
    "middleName": "Иванович",
    "position": "Инженер"
  },
  "documentTitle": "Протокол обучения пользователей №1",
  "csvFilePath": "/Info.csv"
}
```

**Поля конфигурации:**

| Поле | Тип | Описание |
|------|-----|----------|
| `employee.lastName` | string | Фамилия сотрудника |
| `employee.firstName` | string | Имя сотрудника |
| `employee.middleName` | string | Отчество сотрудника |
| `employee.position` | string | Должность сотрудника |
| `documentTitle` | string | Заголовок документа |
| `csvFilePath` | string | Путь к CSV-файлу с данными |

---

### 3. 📊 Info.csv

Файл с данными участников в формате CSV:

```csv
Фамилия,Имя,Оценка
Петров,Петр,5
Сидоров,Сидор,4
Иванов,Иван,3
```

**Структура CSV:**

| Колонка | Тип | Описание |
|---------|-----|----------|
| **Фамилия** | string | Фамилия участника |
| **Имя** | string | Имя участника |
| **Оценка** | integer | Оценка (от 1 до 5) |

> ⚠️ **Важно:** Файл должен быть сохранён в кодировке **UTF-8** для корректного отображения кириллицы.

## 🚀 Запуск и работа

### Шаг 1. Запустите программу

Откройте консоль или Visual Studio и запустите приложение.

### Шаг 2. Укажите путь к конфигурации

Программа попросит ввести полный путь к `config.json`:

```bash
Введите путь к config.json: C:\Projects\CreatReports\config.json
```

> 💡 **Подсказка:** Если файл лежит в папке с программой, можно указать только `config.json`

### Шаг 3. Укажите путь для сохранения

Программа попросит указать, куда сохранить готовый документ:

```bash
Введите путь для сохранения документа: C:\Reports\Protocol_2026.docx
```

> 💡 **Подсказка:** Если папка не существует, программа создаст её автоматически.

### Шаг 4. Дождитесь завершения

Программа покажет сообщение об успешном создании:

```bash
✅ Документ успешно создан: C:\Reports\Protocol_2026.docx
```

### Шаг 5. Продолжить или завершить

Программа спросит о продолжении работы:

```bash
Продолжить? (Y/N):
```

- Нажмите **`Y`** — создать ещё один документ
- Нажмите **любую другую клавишу** — завершить работу

## 💡 Как работает программа

1. 📂 Читает файл `config.json`
2. 📊 Загружает данные из `Info.csv`
3. 📄 Открывает шаблон `SourceTemplate.docx`
4. 🔄 Заменяет все плейсхолдеры на реальные данные
5. 💾 Сохраняет готовый документ по указанному пути

## 🏷️ Метки в шаблоне

| Метка | Описание | Источник данных |
|-------|----------|-----------------|
| `{DocumentTitle}` | Заголовок документа | `config.json` → `documentTitle` |
| `{RowNumberTbl}` | Номер строки в таблице | Генерируется автоматически |
| `{LastNameTbl}` | Фамилия участника | `Info.csv` → `Фамилия` |
| `{FirstNameTbl}` | Имя участника | `Info.csv` → `Имя` |
| `{EvaluationTbl}` | Оценка участника | `Info.csv` → `Оценка` |
| `{Position}` | Должность сотрудника | `config.json` → `employee.position` |
| `{LastName}` | Фамилия сотрудника | `config.json` → `employee.lastName` |
| `{FirstName}` | Имя сотрудника | `config.json` → `employee.firstName` |
| `{MiddleName}` | Отчество сотрудника | `config.json` → `employee.middleName` |

## ⚠️ Возможные ошибки

| Ошибка | Решение |
|--------|---------|
| ❌ **Файл не найден** | Проверьте, что все файлы лежат в указанных местах |
| ❌ **Некорректный формат CSV** | Проверьте колонки: `Фамилия,Имя,Оценка` |
| ❌ **Неправильный JSON** | Проверьте кавычки и запятые в `config.json` |
| ❌ **Нет доступа для записи** | Закройте файл, если он открыт в Word |
| ❌ **Плейсхолдер не найден** | Проверьте написание меток в шаблоне |
