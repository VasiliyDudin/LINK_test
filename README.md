## 📖 Описание

**JustPass** — это клиент-серверное веб-приложение для генерации и временного хранения паролей. Все сгенерированные пароли хранятся **только в рамках сессии браузера** и не сохраняются на сервере. Приложение разработано в минималистичном интуитивно понятном интерфейсе в стилистике компании **ЛУКОЙЛ**.

## 🚀 Запуск приложения

### 1. Запуск сервера

Сервер запускается по адресу:  
**`https://localhost:7227`**

> Если требуется изменить хост или порт, отредактируйте файл:  
> `JustPass.Server/Properties/launchSettings.json`

```bash
cd JustPass.Server
dotnet run
```

### 2. Запуск клиента

Клиент также использует **`https://localhost:7227`** для взаимодействия с сервером.  
Настройки прокси уже прописаны в файлах:
- `App.jsx`
- `PasswordGenerator.jsx`
- `vite.config.js`

```bash
cd JustPass.Client
npm install
npm run dev
```

После запуска клиента приложение будет доступно в браузере.

## 🔄 API Эндпоинты (REST)

Контроллер `PassController.cs` предоставляет следующие методы:

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| **GET** | `/api/pass` | Получить список всех сгенерированных паролей |
| **GET** | `/api/pass/{id}` | Получить пароль по ID |
| **POST** | `/api/pass` | Сгенерировать новый пароль |
| **PUT** | `/api/pass/{id}` | Полное обновление пароля |
| **DELETE** | `/api/pass/{id}` | Удалить пароль из истории |

## 🧪 Демонстрационное шифрование

Для демонстрационных целей при передаче паролей используется **Base64**.  
Это позволяет скрыть реальные пароли от видимости при передаче в запросах.

> 📌 **Как посмотреть реальные пароли:**  
> Откройте **DevTools → Console** в браузере.

## 📦 Модели данных

### `PassRequest`
Запрос на генерацию пароля.
```json
{
  "length": 12,
  "includeNumbers": true,
  "includeSymbols": true,
  "includeUppercase": true
}
```

### `PassResponse`
Ответ сервера с паролем.
```json
{
  "id": "uuid",
  "password": "RXEksi3J",
  "strength": "Weak",
  "createdAt": "2026-08-01T20:44:50Z"
}
```

### `PassHistory`
История сгенерированных паролей.
```json
{
  "items": [
    { "id": 1, "password": "RXEksi3J", "strength": "Weak" },
    { "id": 2, "password": "B@bBM90", "strength": "Excellent" }
  ]
}
```
